# About tab

The **About** tab provides license text, credits, and repository and citation
information. Three buttons switch what is displayed in the text area below them.

| Button | Shows |
|---|---|
| **Legal** | The full GNU General Public License v3 (GPLv3) text |
| **Copyright & Credits** | Copyright notice and the third-party libraries used (PySide6, NumPy, Pydantic, tifffile), with their licenses |
| **Repository** | Version number, source-code and issue-tracker URLs, and the citation |

## Citing Pystern Blot

The **Repository** view includes the citation for Pystern Blot. Citation metadata
is also maintained in the `CITATION.cff` file in the repository, which GitHub
renders as a ready-to-use citation via the **"Cite this repository"** option.
